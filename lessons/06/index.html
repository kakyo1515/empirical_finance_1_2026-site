計算に使う関数を確認する

本回の分析では、第5回で定義したcalculate_npv()とcalculate_irr()を使う。前回の作業領域が保存されていれば、同じProjectを開くと関数も自動復元されるため、再定義する必要はない。Environmentに二つの関数があることを確認する。

関数を保存しておらず、復元されていない場合は、以下の定義をscript/lesson06.Rに記述して実行する。

関数が復元されていない場合の定義 
# 第5回で作成したNPV・IRRの関数を再定義する
calculate_npv <- function(cash_flows, discount_rate,
                          periods = seq_along(cash_flows) - 1) {
  present_values <- cash_flows / (1 + discount_rate)^periods
  sum(present_values)
}

calculate_irr <- function(cash_flows,
                          periods = seq_along(cash_flows) - 1,
                          interval = c(-0.99, 1)) {
  npv_function <- function(rate) {
    calculate_npv(cash_flows, rate, periods)
  }

  result <- uniroot(
    f = npv_function,
    interval = interval,
    tol = 1e-10
  )
  result$root
}

Chapter 1｜tidyverseによるデータ分析

これまでの授業では、Rの基本操作を学んできた。Rでより高度なデータ分析を行うための方法には、さまざまな流派（スタイル）がある。その一つが、tidyverseを使った分析である。

本講義では、今後、tidyverseを使って財務データや株式データを分析していく。そのため、本回ではtidyverseの概要と基本的な操作を紹介する。

1. tidyverseとは

tidyverseは、データ分析のために作られたRのパッケージ群である。各パッケージが共通の設計思想やデータ構造を持ち、読み込み、整理、集計、作図を組み合わせて使える。第4回で使ったreadrもその一つである。tidyverse公式サイト

パッケージ 主な役割
readr データの読み込み
tibble 表形式のデータの扱い
tidyr データの整形
dplyr データの加工・集計
ggplot2 データの可視化

これらは主なパッケージの一部である。本回では、すでに分析しやすい形に整理したCSVを用意し、主にreadr、dplyr、ggplot2を使う。tidyverseのパッケージ一覧

tidyverse流とは、tidyverseのパッケージを使ってデータ分析を行う流派（スタイル）である。Rの標準的な関数や基本構文を中心に使う分析方法と対比した呼び方である。

関数の使い方やデータの扱い方に共通性があるため、異なるパッケージの機能を組み合わせて分析を進めやすい。また、コードから処理の流れを読み取りやすく、分析手順の共有や再利用もしやすい。

本講義では、以降、主にtidyverseのパッケージを使って、財務データと株式データの処理・分析を行う。

2. tidyverseを読み込む

tidyverseパッケージを導入すると、分析に使う中心的なパッケージをまとめてインストールできる。

未導入の場合は、Consoleで次のコードを実行する。

install.packages("tidyverse")

続いて、Rスクリプトに次の行を記述する。Projectのオブジェクトが復元されても、使用するパッケージはlibrary()で読み込む。

library(tidyverse) # dplyrやggplot2などをまとめて読み込む

3. パイプ演算子

パイプ演算子で複数の処理をつなぐ書き方は、tidyverseを代表する特徴の一つである。tidyverseでは、もともと%>%というパイプ演算子が使われてきた。

パイプ演算子%>%を使うと、左側の結果を右側の関数の第1引数へ渡し、処理を実行する順に記述できる。本回で使う投資案Aについて、各キャッシュフローの現在価値を合計し、小数第2位まで表示する。

cash_flows <- c(-100, 30, 40, 50, 30, 25, 20, 15, 10)
present_values <- cash_flows / (1 + 0.08)^(0:8)

round(sum(present_values), digits = 2)
[1] 67.59
# %>%で左側の結果を右側の関数の第1引数へ渡す
present_values %>%
  sum() %>%
  round(digits = 2)
[1] 67.59

どちらも結果は67.59となる。パイプを使ったコードは、「現在価値を合計し、その結果を小数第2位まで丸める」と上から読める。

2021年に公開されたR 4.1.0からは、R標準のパイプ演算子|>も使えるようになった。上の処理は、|>を使って次のように書ける。

# R標準のパイプ|>で、同じ順に「合計→丸める」と処理する
present_values |>
  sum() |>
  round(digits = 2)
[1] 67.59

この例では、%>%と同じ結果が得られる。以下では、パイプ演算子をR標準の|>で統一する。パイプの後で改行すると、各処理を確認しやすい。

練習1： 第5回で定義したcalculate_npv()を使うと、投資案AのNPVは次のように計算できる。このコードを、cash_flowsから始めてパイプ演算子|>で処理をつなぐ形に書き換えなさい。実行し、同じ結果（67.59）が得られることを確認する。

round(calculate_npv(cash_flows, discount_rate = 0.08), digits = 2)
解答例 
cash_flows |>
  calculate_npv(discount_rate = 0.08) |>
  round(digits = 2)

結果は67.59となる。cash_flowsがcalculate_npv()の第1引数に渡され、計算されたNPVがround()の第1引数に渡される。

Chapter 2｜tidyverseの基本操作

ここでは、五つの投資案のキャッシュフローデータを例に、tidyverseによるデータ分析の基本操作を学ぶ。CSVの読み込みから始め、必要な行・列の抽出、新しい列の追加、グループごとの集計、結果の並べ替えを順に行う。一連の操作を通じて、投資案ごとのNPVとIRRを一つの表にまとめ、比較する。

1. データの読み込み

tidyverseでCSV形式のデータを読み込む際には、一般にreadrパッケージのread_csv()を使う。

ここでは、五つの投資案A・B・C・D・EのキャッシュフローをCSVから読み込み、データの内容と構造を確認する。各投資案について、時点0の初期投資から8年後までの金額を記録している。金額の単位は万円とする。

cash_flow_data <- read_csv(

2. データの抽出

tidyverse流では、filter()とselect()を使ってデータを抽出する。filter()は条件を満たす行を、select()は指定した列を取り出す。

ここでは、投資案Aのデータを抽出し、時点とキャッシュフローの列だけを取り出す。

project_a <- cash_flow_data |>
  filter(project == "A") |>   # 条件を満たす行を残す
  select(period, cash_flow)   # 必要な列を選ぶ

これらの関数では、表を第1引数として渡しているため、cash_flow_data$projectではなくprojectのように列名だけを記述できる。

filter()には、複数の条件を指定できる。条件をカンマで区切ると、すべての条件を満たす行が抽出される。例えば、投資案Bのうち、時点1以降の行だけを取り出すには、次のように二つの条件を指定する。

cash_flow_data |>
  filter(project == "B", period >= 1) |> # カンマで並べた条件をすべて満たす行
  select(period, cash_flow)

3. 新しい列の追加

tidyverse流では、mutate()を使って新しい列を追加する。

ここでは、各キャッシュフローを年8%で割り引き、現在価値の列present_valueを加える。

discount_rate <- 0.08

# mutate()で各行を計算し、元の列を残したまま新しい列を追加する
pv_data <- cash_flow_data |>
  mutate(
    present_value = cash_flow / (1 + discount_rate)^period
  )

head(pv_data)

各行のcash_flowとperiodを使って計算する。元の表はcash_flow_dataに残し、現在価値を加えた表をpv_dataに保存している。

練習3： pv_dataに、キャッシュフローを万円単位から円単位に換算した列cash_flow_yenを追加し、結果をpv_yen_dataに保存しなさい。1万円は10,000円である。head()で先頭の行を表示し、元のcash_flow列と見比べること。

解答例 
pv_yen_data <- pv_data |>
  mutate(cash_flow_yen = cash_flow * 10000)

例えば、投資案Aの時点0は−1,000,000円、時点1は300,000円となる。元のcash_flow列を残したまま、円単位の列が追加される。

4. グループごとに集計する

データ分析では、データをグループに分け、グループごとに集計・分析することがある。例えば、企業の財務データを業種別に分けて平均利益を比較したり、株式のリターンデータを銘柄別に分けて平均リターンを求めたりする。

tidyverse流では、group_by()でグループを指定し、summarise()でグループごとの集計を行う。ここでは、投資案ごとにNPVとIRRを計算し、結果を一つの表にまとめる。

(1) group_by()でグループを指定する

group_by()は、指定した列の値が同じ行を、同じグループとして扱うための関数である。group_by(project)とすると、投資案Aの行、Bの行というように、投資案ごとにグループが指定される。dplyr：group_by()

pv_grouped <- pv_data |>
  group_by(project) # 以後の集計を投資案ごとに分けて行う

pv_grouped

# Groups:   project [5]
   project period cash_flow present_value
   <chr>    <dbl>     <dbl>         <dbl>
 1 A            0      -100       -100   
 2 A            1        30         27.8 
 3 A            2        40         34.3 
 4 A            3        50         39.7 
 5 A            4        30         22.1 
 6 A            5        25         17.0 
 7 A            6        20         12.6 
 8 A            7        15          8.75
 9 A            8        10          5.40
10 B            0      -180       -180   
# ℹ 35 more rows

出力のGroups: project [5]は、projectによって五つのグループが指定されていることを表す。グループを指定しただけでは、まだ集計は行われない。表は45行のままで、各行の金額も変わらない。

(2) summarise()でグループごとに集計する

summarise()は、合計や平均などを計算し、各グループの結果を一行にまとめる関数である。新しい列名 = 集計の計算式という形で、結果の列名と計算内容を指定する。summarize()と書いても同じ関数である。dplyr：summarise()

集計に使う関数 内容
sum(x) 合計
mean(x) 平均
n() グループ内の行数

ここでは、先ほどグループを指定したpv_groupedを使い、投資案ごとのNPVとIRRを同時に計算する。NPVは現在価値の合計、IRRは同じグループのキャッシュフローと時点をcalculate_irr()へ渡して求める。

project_results <- pv_grouped |>
  summarise( # 各投資案のデータを1行の集計結果にまとめる
    NPV = sum(present_value),
    IRR = calculate_irr(cash_flow, periods = period)
  ) |>
  mutate(IRR_percent = IRR * 100) # 小数のIRRを百分率に換算する

project_results
# A tibble: 5 × 4
  project   NPV     IRR IRR_percent
  <chr>   <dbl>   <dbl>       <dbl>
1 A        67.6  0.274        27.4 
2 B       136.   0.212        21.2 
3 C       -53.6 -0.0243       -2.43
4 D        33.3  0.112        11.2 
5 E        72.0  0.184        18.4

sum(present_value)は、各投資案に属する9行の現在価値を合計する。calculate_irr()にも、その投資案の9行のキャッシュフローと時点が渡される。結果は、A～Eの各投資案につき一行、合計5行になる。

summarise()の後にmutate()で百分率の列を追加している。IRRは小数、IRR_percentは百分率で表した値となる。

AのNPVは約67.59万円、IRRは約27.44%となる。summarise()にはsum()やmean()だけでなく、第5回で定義した自作関数も使える。

練習4： cash_flow_dataから時点1以降の行を取り出し、投資案ごとのキャッシュフローの平均を求めなさい。結果の列名はmean_cash_flowとする。

解答例 
cash_flow_data |>
  filter(period >= 1) |>
  group_by(project) |>
  summarise(mean_cash_flow = mean(cash_flow))

時点0の初期投資を除き、各投資案の時点1～8のキャッシュフローを平均している。結果は投資案ごとに一行となり、例えばAの平均は27.5万円となる。

5. 結果を並べ替える

五つの投資案をNPVの大きい順に並べ、計算結果を比較する。

arrange()は行を並べ替える。既定では昇順、desc()を付けると降順になる。

project_results |>
  arrange(desc(NPV)) |> # arrange()で並べ替え、desc()で大きい順にする
  select(project, NPV, IRR_percent)
# A tibble: 5 × 3
  project   NPV IRR_percent
  <chr>   <dbl>       <dbl>
1 B       136.        21.2 
2 E        72.0       18.4 
3 A        67.6       27.4 
4 D        33.3       11.2 
5 C       -53.6       -2.43

NPVが大きい順にB、E、A、D、Cとなる。BのNPVは約135.51万円で最も大きく、Cは約−53.58万円となる。このコードは結果を表示するだけであり、project_results自体の並び順は変わらない。

練習5： discount_rateを12%に変更し、pv_dataの作成から集計までを再実行しなさい。NPVとIRRのうち、どちらが変化するか確認する。確認後は8%に戻して同じ処理を再実行し、次の作図へ進む。

解答例 
discount_rate <- 0.12

pv_data <- cash_flow_data |>
  mutate(
    present_value = cash_flow / (1 + discount_rate)^period
  )

project_results <- pv_data |>
  group_by(project) |>
  summarise(
    NPV = sum(present_value),
    IRR = calculate_irr(cash_flow, periods = period)
  ) |>
  mutate(IRR_percent = IRR * 100)

project_results

NPVは変化するが、IRRは変化しない。NPVは指定した割引率で現在価値を求めるため、discount_rateの影響を受ける。一方、IRRはキャッシュフローとその発生時点から求めるため、ここで指定する割引率には依存しない。

確認後は、割引率を8%に戻し、現在価値と集計結果を作り直す。discount_rateの値を変更するだけでは、すでに作成したpv_dataやproject_resultsは更新されない。

discount_rate <- 0.08

pv_data <- cash_flow_data |>
  mutate(
    present_value = cash_flow / (1 + discount_rate)^period
  )

project_results <- pv_data |>
  group_by(project) |>
  summarise(
    NPV = sum(present_value),
    IRR = calculate_irr(cash_flow, periods = period)
  ) |>
  mutate(IRR_percent = IRR * 100)

Chapter 3｜ggplot2によるデータ可視化

これまでのRの基本操作では、plot()やhist()など、Rの標準機能を使った作図方法を学んだ。より見やすい図を作り、色や軸、背景などを柔軟に調整するには、ggplot2が便利である。ここでは、ggplot2の基本的な使い方を学び、棒グラフと折れ線グラフを作成する。

ggplot2は、図を作るためのパッケージであり、tidyverseに含まれている。Chapter 1でlibrary(tidyverse)を実行していれば、そのまま使える。ggplot2の名前にあるggは、Grammar of Graphics（グラフィックスの文法）を表す。データと図の要素を組み合わせる共通の書き方で、さまざまなグラフを作成できる。

作図では、次の四つの手順を基本とする。後で作る棒グラフと折れ線グラフも、この順序で進める。

手順 指定する内容 主に使う関数
(1) データと変数の対応を指定する 作図に使う表を渡し、変数を軸や色などに対応させる ggplot()、aes()
(2) 図の層を加える 棒、点、線など、データを表す図形の層（layer）を加える geom_col()、geom_point()、geom_line()など
(3) ラベルや見た目を整える タイトル、軸ラベル、凡例（legend）、目盛り、背景などを設定する labs()、scale_x_continuous()、theme_classic()など
(4) 図を表示する 作成した図のオブジェクトを画面に表示する print()

図の要素は+で追加する。Chapter 1のパイプ演算子|>が処理結果を次の関数へ渡すのに対し、ggplot2の+は図に層や設定を加える記号である。+の後で改行し、要素を順に書き足す。ggplot2：ggplot()

各手順で作成した図は、オブジェクトに保存して次の手順へ渡す。npv_plot <- ...のように代入しただけでは図は表示されないため、最後にprint(npv_plot)で表示する。本講義では、図の表示にprint()を使う。ggplot2：図の表示

2. NPVの棒グラフ

投資案ごとのNPVを棒の高さで表し、五つの投資案の大小と正負を比較する。使うのは、Chapter 2で作成したproject_resultsである。一行が一つの投資案の結果を表している。

(1) データと変数の対応を指定する

ggplot()に表を渡し、aes()で横軸にproject、縦軸にNPVを対応させる。

# ggplot()で作図の土台を作り、aes()で列と軸の対応を指定する
npv_base <- ggplot(
  data = project_results,
  mapping = aes(x = project, y = NPV)
)
コードの部分 この例での意味
data = project_results 作図に使う表を指定する
mapping = aes(...) 表の変数を図のどこに対応させるか指定する
x = project 投資案を横軸に対応させる
y = NPV NPVを縦軸に対応させる

aes()では、指定した表にある列名をそのまま使える。project_results$NPVのように表の名前を繰り返す必要はない。ggplot2：aes()

この段階では、データと変数の対応を指定しただけであり、棒の層はまだ加えていない。なお、引数の順序を守れば、ggplot(project_results, aes(x = project, y = NPV))と引数名を省略しても同じ指定になる。

(2) 図の層を加える

geom_col()で棒の層を加える。あわせて、geom_hline()でNPVが0となる位置に基準線を加える。

# +で図の層を重ねる（パイプの|>とは異なる）
npv_layers <- npv_base +
  geom_col(fill = "skyblue") + # 集計済みのNPVを棒の高さにし、内側の色を指定する
  geom_hline(yintercept = 0, colour = "gray") # y = 0に基準線を引く

fill = "skyblue"は、すべての棒を同じ水色にする指定である。yintercept = 0は基準線の位置、colour = "gray"はその線の色を指定している。

層（layer）とは、図に重ねる棒、点、線などの要素である。層を加えるgeom_から始まる関数には、次のようなものがあり、表したい内容に応じて選ぶ。ggplot2：関数一覧

関数 図形・グラフと用途
geom_point() 散布図：各観測を点で表す
geom_line() 折れ線グラフ：観測を横軸の順に線で結ぶ
geom_smooth() 平滑線：データの傾向を線で表す
geom_bar() 棒グラフ：既定ではカテゴリごとの件数を表す
geom_col() 棒グラフ：計算済みの数値を棒の高さで表す
geom_histogram() ヒストグラム：数値を区間に分け、件数を表す
geom_polygon() 多角形（ポリゴン）：頂点を結んだ領域を塗りつぶす
geom_map() 地図：地図データに基づいて地域の領域を描く
geom_dotplot() ドットプロット：値を区間に分け、件数を点の積み重ねで表す
geom_hline() 水平線：指定した縦軸の位置に基準線などを引く

同じ棒グラフでも、件数を数える場合はgeom_bar()、NPVのようにすでに計算した値を表示する場合はgeom_col()を使う。ggplot2：棒グラフ

(3) ラベルや見た目を整える

labs()で図のタイトルと軸ラベルを付け、theme_classic()で背景や軸線などの見た目を整える。

# labs()でタイトルと軸名を設定する（データの値は変えない）
npv_plot <- npv_layers +
  labs(
    title = "NPV by Project",
    x = "Project",
    y = "NPV (10,000 yen)"
  ) +
  theme_classic() # 白い背景と軸線だけのテーマにする

labs()のtitleは図全体のタイトル、xは横軸の名前、yは縦軸の名前である。金額の単位は万円なので、縦軸に10,000 yenと記載している。ラベルを変えても、表の列名や値は変わらない。

theme_classic()では背景が白くなり、グリッド線がなくなる。テーマを変えても、NPVの値や棒の高さは変わらない。主なテーマには、次のようなものがある。ggplot2：テーマ

テーマ 主な見た目
theme_gray() 既定の灰色の背景とグリッド線
theme_bw() 白い背景、枠線、グリッド線
theme_classic() 白い背景と軸線、グリッド線なし
theme_minimal() 背景や枠の装飾を抑えた見た目

(4) 図を表示する

完成した図のオブジェクトnpv_plotをprint()に渡す。

print(npv_plot)

NPVが正の投資案の棒は0から上に伸び、負のCの棒は0から下に伸びる。BのNPVが最も大きく、Cだけが負となっていることを確認する。完成した図はnpv_plotに保存されており、後で画像ファイルとして出力できる。

作図コードのまとめ

四つの手順をまとめると、次のように書ける。project_resultsを使い、上と同じ棒グラフを作成する。

# (1) データと変数の対応を指定する
npv_plot <- ggplot(
  data = project_results,
  mapping = aes(x = project, y = NPV)
) +
  # (2) 図の層を加える
  geom_col(fill = "skyblue") +
  geom_hline(yintercept = 0, colour = "gray") +
  # (3) ラベルや見た目を整える
  labs(
    title = "NPV by Project",
    x = "Project",
    y = "NPV (10,000 yen)"
  ) +

# (4) 図を表示する

練習6： 縦軸をIRR_percentに変更し、IRRを比較する棒グラフを作りなさい。縦軸名は"IRR (%)"、図のタイトルは"IRR by Project"とする。

解答例 
# (1) データと変数の対応を指定する
irr_base <- ggplot(
  data = project_results,
  mapping = aes(x = project, y = IRR_percent)
)

# (2) 図の層を加える
irr_layers <- irr_base +
  geom_col(fill = "skyblue") +
  geom_hline(yintercept = 0, colour = "gray")

# (3) ラベルや見た目を整える
irr_plot <- irr_layers +
  labs(
    title = "IRR by Project",
    x = "Project",
    y = "IRR (%)"
  ) +
  theme_classic()

# (4) 図を表示する
print(irr_plot)

aes()の縦軸をIRR_percentに、labs()の縦軸名を"IRR (%)"に、タイトルを"IRR by Project"に変更している。百分率の列を使うため、例えばAの棒の高さは約27.44となる。

3. キャッシュフローの折れ線グラフ

時点ごとのキャッシュフローを点と線で表し、投資案ごとの支払いや受取りの違いを比較する。Chapter 2で読み込んだcash_flow_dataを使い、棒グラフと同じ四つの手順で作成する。

(1) データと変数の対応を指定する

横軸にperiod、縦軸にcash_flowを対応させる。投資案ごとの違いを表すため、aes()にcolour = projectも指定する。

cash_flow_base <- ggplot(
  data = cash_flow_data,
  mapping = aes(x = period, y = cash_flow, colour = project) # 投資案ごとに色分けする
)

colour = projectは色名を指定する命令ではなく、projectの値に応じて色を分ける指定である。図を表示すると、A～Eに異なる色が割り当てられ、色と投資案の対応を示す凡例（legend）も表示される。

(2) 図の層を加える

geom_point()で点、geom_line()で線の層を加える。金額の正負を見比べるため、0の位置に基準線も加える。

cash_flow_layers <- cash_flow_base +
  geom_point() + # 各時点の値を点で描く
  geom_line() +  # 同じ投資案の点を時点順に結ぶ
  geom_hline(yintercept = 0, colour = "gray")

一つの点が、一つの投資案の一つの時点の金額を表す。geom_line()は横軸の値の順に点を結ぶ。この例では、projectを色に対応させているため、投資案ごとに別の線が描かれる。データとaes()の指定は、ggplot()で作った土台から点と線の層へ引き継がれる。ggplot2：折れ線グラフ

線は各時点の金額の変化を見比べるためのものであり、時点の間にもキャッシュフローが発生するという意味ではない。

(3) ラベルや見た目を整える

labs()で図のタイトルと軸・凡例の名前を付け、scale_x_continuous()で横軸の目盛りを設定する。テーマは棒グラフと同じtheme_classic()を使う。

cash_flow_plot <- cash_flow_layers +
  labs(
    title = "Cash Flows by Project",
    x = "Year",
    y = "Cash flow (10,000 yen)",
    colour = "Project" # 色の凡例のタイトル
  ) +
  scale_x_continuous(breaks = 0:8) + # 横軸の目盛りを0から8まで1刻みにする
  theme_classic()

labs()のcolourは、色の凡例の見出しを設定する引数である。aes(colour = project)が色分けに使う変数を指定するのに対し、labs(colour = "Project")は凡例に表示する名前を指定している。

breaks = 0:8は、時点0～8をすべて横軸の目盛りに表示する指定である。目盛りの表示を変える設定であり、データの時点や金額は変わらない。

(4) 図を表示する

完成した図のオブジェクトcash_flow_plotを表示する。

print(cash_flow_plot)

完成した図では、Eの時点3に追加の支払いがあることや、Dでは受取りが時点3から始まることを確認できる。NPVだけでは見えない、資金の動きも比較できる。

作図コードのまとめ

折れ線グラフも、同じ四つの手順をまとめて書ける。cash_flow_dataを使い、上と同じ図を作成する。

# (1) データと変数の対応を指定する
cash_flow_plot <- ggplot(
  data = cash_flow_data,
  mapping = aes(x = period, y = cash_flow, colour = project)
) +
  # (2) 図の層を加える
  geom_point() +
  geom_line() +
  geom_hline(yintercept = 0, colour = "gray") +
  # (3) ラベルや見た目を整える
  labs(
    title = "Cash Flows by Project",
    x = "Year",
    y = "Cash flow (10,000 yen)",
    colour = "Project"
  ) +
  scale_x_continuous(breaks = 0:8) +
  theme_classic()

# (4) 図を表示する
print(cash_flow_plot)

4. 図を保存する

完成したNPVの棒グラフを、Project内のoutputフォルダに画像ファイルとして保存する。

図を画面に表示するだけでは、画像ファイルは保存されない。ggsave()に保存先と図のオブジェクトを渡す。

# ggsave()で指定したggplotの図をファイルに保存する
ggsave(
  filename = "output/npv-comparison.png",
  plot = npv_plot,
  width = 7,
  height = 4.5,
  units = "in", # widthとheightの単位はインチ
  dpi = 160     # 画像の解像度
)
引数 この例での指定
filename 保存先とファイル名。.pngでPNG画像を指定する
plot 保存する図のオブジェクト。ここでは完成したnpv_plot
width、height 画像の幅と高さ
units 幅と高さの単位。"in"はインチ
dpi 一インチ当たりの画素数。ここでは160を指定する

plot = npv_plotと明示することで、途中で表示した図ではなく、完成したNPVの棒グラフを保存できる。ggplot2：ggsave()

同名のファイルは上書きされる。保存後はFilesペインでoutput/npv-comparison.pngを開き、図が保存されていることを確認する。ggsave()が画像の出力を行うため、dev.off()は不要である。
