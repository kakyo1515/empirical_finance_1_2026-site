Chapter 1｜ベクトル

データ構造とは

データ構造とは、データをコンピュータの中でどのようにまとめ、並べて保持するかを決める仕組みである。データを適切な形に整理すると、必要な値を取り出したり、まとめて計算したりしやすくなる。

例えば、学生の得点だけを扱うなら、値を一列に並べればよい。一方、学生ごとに氏名、得点、合否を対応させて扱うなら、行と列を持つ表の形が便利である。このように、データの内容や使い方に応じて、適した構造を選ぶ。

前回学んだデータ型が「数値、文字列、論理値など、値の種類」を表すのに対し、データ構造は「値のまとめ方や並べ方」を表す。本回では、Rの主なデータ構造として次の五つを学ぶ。

データ構造 特徴 使用例
ベクトル 同じ型の値を一列に並べる 学生5人の得点
行列 同じ型の値を行と列に並べる 学生ごとの複数回のテスト得点
配列 同じ型の値を複数の次元に沿って並べる 学生・科目・学期ごとの得点
データフレーム 列ごとに異なる型を持てる表にまとめる 氏名、得点、合否の一覧
リスト 型や構造、大きさの異なるオブジェクトをまとめる 説明文、得点の表、分析結果のまとまり

まずは、同じ型の値をひとまとめにする基本的な構造であるベクトルから見ていこう。

1. 複数の値の格納

複数の学生の得点を扱うとき、学生ごとに別のオブジェクトを作る必要はない。ベクトルを使えば、同じ型の値をひとまとめにできる。c()は、引数に指定した値を順に結合する関数である。

# c()で複数の値を一つのベクトルにまとめる
scores <- c(72, 85, 91, 68, 77)
student_names <- c("Aiko", "Ken", "Mei", "Sora", "Yuki")

scores
[1] 72 85 91 68 77
student_names
[1] "Aiko" "Ken"  "Mei"  "Sora" "Yuki"

length()で要素数、class()でデータ型を確認する。

length(scores) # ベクトルの要素数を数える
[1] 5
class(scores)
[1] "numeric"
class(student_names)
[1] "character"

規則的な並びには専用の記法や関数がある。:は連続する整数、seq()は等間隔の数列、rep()は同じ値の繰り返しを作る。

1:5                           # :で1刻みの数列を作る
[1] 1 2 3 4 5
seq(from = 0, to = 10, by = 2)  # 開始値・終了値・間隔を指定する
[1]  0  2  4  6  8 10
rep("A", times = 4)            # 同じ値を4回繰り返す
[1] "A" "A" "A" "A"

練習1： 50から100まで、10刻みのベクトルを作りなさい。

解答例 
seq(from = 50, to = 100, by = 10)

seq(from = 0, to = 1, length.out = 6)のように、間隔ではなく要素数を指定することもできる。

2. ベクトルによる計算

ベクトルに数値を足したり、割ったりすると、それぞれの要素に計算が適用される。次のコードでは、得点に5点を加えた値と、100で割った値を求める。scores自体は書き換わらない。

# ベクトルと数値の計算は、各要素に同じ処理を行う
scores + 5
[1] 77 90 96 73 82
scores / 100
[1] 0.72 0.85 0.91 0.68 0.77

合計や平均は、ベクトルを関数に渡して求める。

sum(scores)  # 合計
[1] 393
mean(scores) # 平均値
[1] 78.6
min(scores)  # 最小値
[1] 68
max(scores)  # 最大値
[1] 91

平均は78.6点である。このように、複数の値を一度に処理できることがRの特徴の一つである。

同じ長さのベクトル同士では、同じ位置の要素が計算される。2回の小テストの合計点と平均点を求めてみよう。

quiz_1 <- c(8, 7, 9, 6)
quiz_2 <- c(7, 9, 8, 8)

# 同じ長さのベクトルどうしは、同じ位置の要素を計算する
quiz_1 + quiz_2
[1] 15 16 17 14
(quiz_1 + quiz_2) / 2
[1] 7.5 8.0 8.5 7.0
補足：長さの異なるベクトル

長さの異なるベクトルを計算すると、短い側の値が繰り返し使われる。例えば、次のコードでは、c(1, 2)がc(1, 2, 1, 2)のように繰り返され、計算は10 + 1、20 + 2、30 + 1、40 + 2となる。

# 短いベクトルを繰り返して長さを合わせる（リサイクル）
c(10, 20, 30, 40) + c(1, 2)
[1] 11 22 31 42

3. 必要な要素の抽出

ベクトルの後ろに角括弧[]を付け、取り出す位置を指定する。Rでは、先頭の位置を1で表す。

scores[1]           # []に位置を指定する（先頭は1）
[1] 72
scores[c(1, 3, 5)]   # 複数の位置を指定する
[1] 72 91 77
scores[2:4]         # 2番目から4番目まで取り出す
[1] 85 91 68

条件による抽出もできる。まず、条件式だけを実行して結果を確認する。

scores >= 80
[1] FALSE  TRUE  TRUE FALSE FALSE

各得点について、条件を満たす位置にTRUE、満たさない位置にFALSEが返る。この結果を[]に入れると、TRUEに対応する要素が選ばれる。

scores[scores >= 80] # 条件がTRUEの位置の要素だけを取り出す
[1] 85 91

抽出されるのは85点と91点である。要素に名前を付けると、位置だけでなく名前でも指定できる。

names(scores) <- student_names # 各要素に名前を付ける

scores
Aiko  Ken  Mei Sora Yuki 
  72   85   91   68   77 
scores["Mei"] # 位置の代わりに名前を指定して取り出す
Mei 
 91

同じ記法で、指定した要素を書き換えられる。ここでは元の得点を残すため、コピーを作ってからKenの得点を修正する。

revised_scores <- scores
revised_scores["Ken"] <- 88 # 指定した要素だけを更新する
revised_scores
Aiko  Ken  Mei Sora Yuki 
  72   88   91   68   77

練習2： scoresから80点以上の得点を取り出し、該当する学生の名前も確認しなさい。

解答例 
scores[scores >= 80]
names(scores[scores >= 80])

KenとMeiが該当する。

4. 欠損値の処理

値が記録されていない場合、Rでは通常NAで表す。欠損値は0とは異なる。次のデータでは、4人のうち1人の得点が不明である。

scores_missing <- c(70, 85, NA, 90) # NAは欠損値を表す

mean(scores_missing)
[1] NA

得点が一つでも不明なため、そのままでは平均もNAになる。欠損値を除いて計算する場合は、na.rm = TRUEを指定する。

mean(scores_missing, na.rm = TRUE) # na.rm = TRUEで欠損値を除いて計算する
[1] 81.66667

これは得点が記録されている3人の平均であり、4人全員の平均ではない。欠損値を除くときは、計算対象が変わることに注意する。

欠損値の位置は、is.na()で調べる。== NAでは判定できない。

is.na(scores_missing)                # 欠損値の位置をTRUEで示す
[1] FALSE FALSE  TRUE FALSE
scores_missing[!is.na(scores_missing)] # 欠損でない要素だけを残す
[1] 70 85 90

!は条件を反転させるため、!is.na()は「欠損していない」という条件になる。

練習3： scores_missingの欠損値を除いた合計を求めなさい。

解答例 
sum(scores_missing, na.rm = TRUE)

結果は245となる。

Chapter 2｜行列（matrix）

1. 行と列からなるデータの作成

行列は、同じ型の値を行と列に並べた二次元のデータ構造である。例えば、3人の学生が受けた2回のテストの得点を、行が学生、列がテストとなるように整理できる。

matrix()のnrowで行数を指定する。byrow = TRUEは、値を行方向に順に並べる指定である。

# matrix()で値を行と列に並べる
score_matrix <- matrix(
  c(80, 75,
    68, 72,
    91, 88),
  nrow = 3,     # 行数を指定する
  byrow = TRUE  # 行方向に値を並べる（既定は列方向）
)

score_matrix
     [,1] [,2]
[1,]   80   75
[2,]   68   72
[3,]   91   88

1行目には80と75、2行目には68と72、3行目には91と88が入る。byrowを指定しない場合は、列方向に並ぶ。

matrix(1:6, nrow = 3)
     [,1] [,2]
[1,]    1    4
[2,]    2    5
[3,]    3    6
matrix(1:6, nrow = 3, byrow = TRUE)
     [,1] [,2]
[1,]    1    2
[2,]    3    4
[3,]    5    6

同じ値でも並べ方によって位置が変わることを確認する。dim()は行数と列数、nrow()は行数、ncol()は列数を返す。

dim(score_matrix)  # 行数と列数をまとめて確認する
[1] 3 2
nrow(score_matrix) # 行数
[1] 3
ncol(score_matrix) # 列数
[1] 2

2. 行名・列名の設定と要素の抽出

rownames()とcolnames()で行と列に名前を付ける。

rownames(score_matrix) <- c("Aiko", "Ken", "Mei") # 行名を付ける
colnames(score_matrix) <- c("Test1", "Test2")      # 列名を付ける
score_matrix
     Test1 Test2
Aiko    80    75
Ken     68    72
Mei     91    88

行列の要素は[行, 列]で指定する。片方を空欄にすると、その方向のすべてを選ぶ。

score_matrix[2, 1]           # [行, 列]の順に位置を指定する
[1] 68
score_matrix["Ken", "Test1"] # 行名と列名でも指定できる
[1] 68
score_matrix[, "Test2"]     # 行を省略すると全行を取り出す
Aiko  Ken  Mei 
  75   72   88 
score_matrix[1:2, ]         # 列を省略すると全列を取り出す
     Test1 Test2
Aiko    80    75
Ken     68    72

最初の二つはどちらもKenのTest1の得点、68を返す。

補足：行列形式を保持した1列の抽出

通常、1列だけを取り出すとベクトルになる。行列の構造を保つにはdrop = FALSEを指定する。

score_matrix[, "Test2", drop = FALSE] # 1列でも行列の形を保つ
     Test2
Aiko    75
Ken     72
Mei     88

3. 行・列ごとの計算

rowMeans()は行ごと、colMeans()は列ごとの平均を求める。この例では、それぞれ学生別、テスト別の平均になる。

rowMeans(score_matrix) # 行ごとの平均値
Aiko  Ken  Mei 
77.5 70.0 89.5 
colMeans(score_matrix) # 列ごとの平均値
   Test1    Test2 
79.66667 78.33333

rbind()は上下、cbind()は左右に結合する。次のコードでは、学生を1人追加した表と、平均点の列を追加した表をそれぞれ表示する。元のscore_matrixは書き換わらない。

rbind(score_matrix, Yuki = c(76, 81))                  # 行を追加する
     Test1 Test2
Aiko    80    75
Ken     68    72
Mei     91    88
Yuki    76    81
cbind(score_matrix, Average = rowMeans(score_matrix)) # 列を追加する
     Test1 Test2 Average
Aiko    80    75    77.5
Ken     68    72    70.0
Mei     91    88    89.5

練習4： 1から6までの値を行方向に並べた3行2列の行列を作り、行名と列名を付けなさい。その後、2行目を取り出し、各列の平均を求めなさい。

解答例 
m <- matrix(1:6, nrow = 3, byrow = TRUE)
rownames(m) <- c("row1", "row2", "row3")
colnames(m) <- c("col1", "col2")

m[2, ]
colMeans(m)

2行目は3と4、列の平均は3と4である。

補足：要素ごとの演算と行列積

行列への加算や乗算は、通常は要素ごとに行われる。t()は行と列を入れ替える転置である。

score_matrix + 5
     Test1 Test2
Aiko    85    80
Ken     73    77
Mei     96    93
score_matrix * 2
     Test1 Test2
Aiko   160   150
Ken    136   144
Mei    182   176
t(score_matrix) # 行と列を入れ替える（転置）
      Aiko Ken Mei
Test1   80  68  91
Test2   75  72  88

二つの行列の*は対応する要素同士の積、%*%は行列積である。行列積では、左側の列数と右側の行数が一致する必要がある。

m1 <- matrix(1:4, nrow = 2, byrow = TRUE)
m2 <- matrix(c(2, 0, 1, 3), nrow = 2, byrow = TRUE)
m1 * m2   # 同じ位置の要素どうしの掛け算
     [,1] [,2]
[1,]    2    0
[2,]    3   12
m1 %*% m2 # 行列積（行と列の積の和）
     [,1] [,2]
[1,]    4    6
[2,]   10   12

Chapter 3｜配列（array）

1. 三次元以上のデータ

配列は、同じ型の値を複数の次元に沿って並べたデータ構造である。行列は二次元の配列に当たり、array()を使うと三次元以上にも拡張できる。

例えば、「学生 × テスト × 週」の得点を考える。3人が毎週2回のテストを受け、その記録が2週分あれば、3行2列の行列を2枚重ねた構造として表せる。

# array()で行・列・週の3次元に値を並べる
score_array <- array(
  c(80, 68, 91, 75, 72, 88,
    84, 70, 93, 78, 76, 90),
  dim = c(3, 2, 2) # 各次元の大きさ：3人・2科目・2週
)

score_array
, , 1

     [,1] [,2]
[1,]   80   75
[2,]   68   72
[3,]   91   88

, , 2

     [,1] [,2]
[1,]   84   78
[2,]   70   76
[3,]   93   90

dim = c(3, 2, 2)は、学生3人、テスト2回、週2つに対応する。値は第1次元から順に埋まるため、最初の3個が第1週のTest1、次の3個が第1週のTest2となり、残りの6個が第2週に入る。matrix(..., byrow = TRUE)とは並べ方が異なる点に注意する。

dim(score_array)
[1] 3 2 2
length(score_array)
[1] 12

dim()の結果は3 2 2、要素数は3 × 2 × 2 = 12である。

2. 次元ごとの位置の指定

三次元配列では、[学生, テスト, 週]の順に指定する。省略した次元では、すべての要素を選ぶ。

score_array[2, 1, 2] # [人, 科目, 週]の順に指定する
[1] 70
score_array[, , 1]  # 第1週の全員・全科目を取り出す
     [,1] [,2]
[1,]   80   75
[2,]   68   72
[3,]   91   88
score_array[1, , ]  # 1人目の全科目・全週を取り出す
     [,1] [,2]
[1,]   80   84
[2,]   75   78

最初の式は、2人目の学生の第2週・Test1の得点70を返す。次の式は第1週の全得点、最後の式は1人目の学生についてテストと週を並べた表を返す。

3. 部分データの抽出と集計

第2週を取り出すと行列になるため、rowMeans()など、行列で学んだ関数を利用できる。

week2_scores <- score_array[, , 2]
rowMeans(week2_scores)
[1] 81.0 73.0 91.5
mean(week2_scores)
[1] 81.83333

学生別平均は81、73、91.5点である。全体の平均は、第2週の6個の得点を対象としている。

練習5： 第2週のTest2の得点を取り出し、その平均を求めなさい。

解答例 
week2_test2 <- score_array[, 2, 2]
week2_test2
mean(week2_test2)

得点は78、76、90、平均は約81.33点となる。

Chapter 4｜データフレーム

1. 表形式のデータの作成

氏名、所属クラス、得点、出席率を一つの表にまとめるには、データフレームを使う。データフレームは列ごとに異なる型を持てる。ここでは、1行が1人の学生、1列が一つの項目に対応する。

# data.frame()で、列ごとに異なる型を持てる表を作る
student_data <- data.frame(
  name = student_names,
  class = c("A", "A", "B", "B", "A"),
  score = c(72, 85, 91, 68, 77),
  attendance = c(0.90, 0.95, 1.00, 0.75, 0.88)
)

student_data
  name class score attendance
1 Aiko     A    72       0.90
2  Ken     A    85       0.95
3  Mei     B    91       1.00
4 Sora     B    68       0.75
5 Yuki     A    77       0.88

data.frame()の各引数で列名と値を指定している。文字列の列と数値の列が、同じ表に含まれていることを確認しよう。

表を扱う前に、行数・列数、列名、各列の型を確認する。dim()は行数と列数、names()は列名、str()は全体の構造を表示する。

dim(student_data)
[1] 5 4
names(student_data) # 表の列名を確認する
[1] "name"       "class"      "score"      "attendance"
str(student_data)   # 各列の型と値の一部を確認する
'data.frame':   5 obs. of  4 variables:
 $ name      : chr  "Aiko" "Ken" "Mei" "Sora" ...
 $ class     : chr  "A" "A" "B" "B" ...
 $ score     : num  72 85 91 68 77
 $ attendance: num  0.9 0.95 1 0.75 0.88

行数だけならnrow()、列数だけならncol()を使う。head()は先頭の行を表示する関数で、行数の多いデータの確認に用いる。

nrow(student_data)
[1] 5
ncol(student_data)
[1] 4
head(student_data, n = 3) # 先頭3行を表示する
  name class score attendance
1 Aiko     A    72       0.90
2  Ken     A    85       0.95
3  Mei     B    91       1.00

2. 列・行・条件による抽出

一つの列を取り出すには、データフレーム名$列名と書く。取り出した得点の列はベクトルなので、先ほどと同じ関数を使って平均を求められる。

student_data$score # $で列をベクトルとして取り出す
[1] 72 85 91 68 77
mean(student_data$score)
[1] 78.6

行と列を同時に指定する場合は、[行, 列]と書く。片方を空欄にすると、その方向のすべてを選ぶ。

student_data[2, 3]
[1] 85
student_data[2, ]
  name class score attendance
2  Ken     A    85       0.95
student_data[, c("name", "score")]
  name score
1 Aiko    72
2  Ken    85
3  Mei    91
4 Sora    68
5 Yuki    77

順に、2行3列目の値、2行目の全項目、全学生の氏名と得点を取り出している。行の指定には条件式も使える。

# 行の条件と、残したい列名を[行, 列]で指定する
student_data[
  student_data$score >= 80,
  c("name", "score")
]
  name score
2  Ken    85
3  Mei    91

コンマの前が行の条件、後ろが列の指定である。コードが複数行に分かれていても、[]全体で一つの処理になる。

3. 列の追加

student_data$passed <- student_data$score >= 60 # 新しい列名への代入で列を追加する

Chapter 5｜リスト（list）

1. 異なる構造のデータの格納

ベクトル、行列、配列では、ここまで同じ型の値を扱ってきた。一方、分析結果には、説明文、表、行列などをまとめて保存したい場合がある。リストは、このように型や構造、大きさの異なるオブジェクトを一つにまとめるデータ構造である。

list()の各引数に名前を付けて、これまでに作成したデータをまとめる。

# list()で文字列・表・行列などを一つにまとめる
course_result <- list(
  course = "R入門",
  students = student_data,
  test_scores = score_matrix,
  weekly_scores = score_array
)

3. 要素の追加

$と代入で、新しい要素を追加できる。

# 新しい要素名への代入でリストに要素を追加する
course_result$average_score <- mean(student_data$score)

practice_result <- list(
